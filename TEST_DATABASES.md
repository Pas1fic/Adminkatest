# Изолированные тестовые базы данных

В админ-панели супер-администратора добавлен раздел **Тестовые базы данных**. Он работает с тремя отдельными SQLite-файлами из каталога test_databases/ и не изменяет основную data/admin.sqlite3.

## Подключённые базы

| База | Таблица | Тестовых записей |
|---|---|---:|
| news.db | news | 100 |
| profile_support.db | support_messages | 2 |
| profile_yammer.db | yammer_messages | 2 |

Схемы таблиц и названия колонок сохранены. Данные в двух профильных базах обезличены перед добавлением в репозиторий: имена, email, идентификаторы и вложения заменены тестовыми значениями. Локальные исходные файлы в db/ не изменяются и исключены из Git.

## Возможности

- Просмотр таблиц и колонок с исходными именами.
- Поиск по текстовым и числовым полям, постраничная навигация.
- Добавление, редактирование и удаление записей.
- Загрузка файлов в BLOB-колонки (например, proof).
- BLOB-вложения отображаются как размер; при обычном редактировании сохраняются без изменений.
- Операции доступны только супер-администратору и записываются в журнал аудита основной панели.

## Расположение файлов

По умолчанию тестовые файлы читаются из test_databases/. Для подключения другого набора SQLite-файлов можно задать переменную окружения ADMIN_TEST_DB_DIR до запуска сервера. Имена файлов и таблиц всё равно должны соответствовать фиксированному списку в app.py.

Не размещайте реальные персональные данные, токены, пароли или пользовательские вложения в публичном репозитории. Для локальных исходников предусмотрена папка db/, которая исключена из Git.
